# SDLC Skills Pack
Seven skills that take an app from idea to production.
- sdlc-orchestrator: phases + gates, coordinates roles
- end-user-uat: PRD, stories, UAT
- architect: design, NFRs, ADRs
- developer: build, tests, PRs
- qa-engineer: test strategy, automation, sign-off
- security-engineer: threat model, secure SDLC
- devops-engineer: CI/CD, IaC, observability, ops
Install: copy each folder into your skills directory (or upload each .skill file). Start with: "Use sdlc-orchestrator to build <your app>".
